# Mission 1 — Know Your Computer

## Task 1.1 — Input, Processing, Output and Storage (IPOS)

Activity: Typing my name on my MacBook.

| Stage | Explanation |
|---|---|
| Input | I type my name using the keyboard. |
| Processing | The CPU processes the keystrokes into characters. |
| Output | My name appears on the monitor screen. |
| Storage | When I press Cmd + S, the file is saved permanently on my Mac's SSD. Temporary data is also held in RAM while I work. |

### How data moves

When I type my name, the keyboard sends input to the computer. The CPU processes it, and the text appears on the screen. When I save the file, it is stored on the SSD.

## Task 1.2 — Identify Hardware and Software

### Hardware

| Hardware | Purpose |
|---|---|
| Keyboard | Used to enter text and commands. |
| SSD | Used to store data permanently. |
| Monitor | Displays visual information. |
| Mouse | Used to control the pointer and select or drag items. |
| CPU | Processes instructions and performs calculations. |

### Software

| Software | Classification | Purpose |
|---|---|---|
| macOS | OS | Manages hardware, memory, files and applications. |
| Google Chrome | Application | Used to browse websites. |
| Visual Studio Code | Application | Used to write and edit programming code. |
| Activity Monitor | Utility | Monitors CPU, memory and system resources. |

## Understanding

I learned how input, processing, output and storage work together. I also learned the difference between hardware and software.

## Difficulties Faced

I initially found it difficult to understand the difference between RAM and SSD.

## How I Resolved Them

I learned that RAM stores temporary working data, while an SSD stores files permanently.
