# Mission 1 — Know your computer

## 1. Task / objective
Explain how a computer receives input, processes information, produces output and stores results. Identify hardware, software and computer-based systems.

## 2. Work completed

### Task 1.1 — Input, Processing, Output and Storage (IPOS)
**Activity:** Typing my name on my MacBook.

| Stage | Explanation | Possible hardware / component |
|---|---|---|
| Input | I type my name using the keyboard. | Keyboard |
| Processing | The CPU processes the keystrokes into characters. | CPU / processor and RAM |
| Output | My name appears on the monitor screen. | Screen / monitor |
| Storage | When I press Cmd + S, the file is saved permanently on my Mac's SSD. Temporary data is also held in RAM while I work. | SSD (Solid State Drive) |

#### How data moves
When I type my name, the keyboard sends input signals to the computer. The CPU processes the input, stores temporary data in RAM, and sends display data so the text appears on the screen. When I save the file, the operating system writes the data to the SSD for permanent storage.

## 4. My understanding
I learned how input, processing, output, and storage (IPOS) work in harmony to execute everyday computing tasks. I also learned the distinction between hardware (physical devices) and three major categories of software: operating systems (manage resources), application software (user productivity), and utility software (system maintenance and monitoring).

## 5. Difficulties faced
I initially found it difficult to understand the conceptual and physical difference between volatile memory (RAM) and non-volatile storage (SSD).

## 6. How I resolved them
I researched computer memory architecture and learned that RAM holds temporary data during active CPU processing and is wiped upon power-off, whereas an SSD retains data permanently even after the machine shuts down.
